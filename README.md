# Ecommerce-Sales-Dashboard (Interactive Dashboard Creation using Power BI)

## Project Objective

The objective of this project is to analyze ecommerce sales data and create an interactive Power BI dashboard that helps understand sales performance, profitability, customer behavior, product categories, payment methods, and regional performance.

The dashboard provides an interactive view of key business metrics and helps identify trends and patterns in ecommerce sales.

## Dataset Used

Ecommerce Sales Dataset

The dataset includes information related to:

- Customer Name
- State
- Category
- Sub-Category
- Payment Mode
- Quantity
- Amount
- Profit
- Order/Transaction details
- Monthly and quarterly sales information

## Questions (KPIs)

1. What is the total sales amount?
2. What is the total profit?
3. What is the total quantity sold?
4. What is the Average Order Value (AOV)?
5. Which states generate the highest sales?
6. Which customers contribute the highest sales?
7. Which categories have the highest quantity sold?
8. Which payment modes are most frequently used?
9. How does profit vary by month?
10. Which sub-categories generate the highest profit?
11. How does business performance vary across quarters?

## Process

1. Gathered the ecommerce dataset and defined the analysis requirements.
2. Imported the dataset into Power BI.
3. Performed data cleaning and transformation using Power Query.
4. Checked data types and handled data quality issues.
5. Created required calculated columns and measures using DAX.
6. Created KPI cards for key business metrics.
7. Developed charts to analyze sales, quantity, and profit.
8. Added quarterly filters for interactive analysis.
9. Designed and formatted the Power BI dashboard.
10. Analyzed the dashboard to identify important business insights.

## Dashboard

The dashboard includes:

- Total Sales Amount
- Total Profit
- Total Quantity
- Average Order Value
- Sales by State
- Quantity by Category
- Profit by Month
- Sales by Customer
- Quantity by Payment Mode
- Profit by Sub-Category
- Quarterly Analysis

## Project Insights

- Maharashtra generated the highest sales amount among the states shown in the dashboard.
- Sales contribution varies across different customers.
- Clothing contributes a significant share of the quantity sold.
- Different payment modes contribute differently to the overall quantity.
- Monthly profit shows variation across October, November, and December.
- Sub-category analysis shows differences in profitability across products.
- Quarterly filtering allows performance to be compared across different periods.

## Final Conclusion

The Ecommerce Sales Dashboard provides an interactive overview of ecommerce business performance. By analyzing sales, profit, quantity, customers, categories, payment modes, and sub-categories, the dashboard helps transform raw ecommerce data into meaningful business insights.

This project demonstrates the use of Power BI, Power Query, and DAX to clean, analyze, visualize, and present data through an interactive business intelligence dashboard.
